THE RULES
Make three in a row.
X plays first. Alternate placing marks in empty squares. A horizontal, vertical or diagonal line of three wins. A full board without a winner is a draw.
Use the mouse, touch, arrow keys and Enter, or number keys 1–9. Difficulty changes the features and questions shown to JEV, not the rules.
Ranked matches require Discord and expire after 15 minutes. Resigning or leaving a human turn until expiration counts as a loss. A service failure or fallback is not an official JEV result.
Result rate = (wins + 0.5 × draws) / completed games. Ranked boards separate human mark, model, profile and policy. External solver use cannot be ruled out.


DATA & PRIVACY
Game evidence, not surveillance.
The server stores placements, timestamps, JEV requests and responses, configuration fingerprints, result verification, and short-lived rate counters. Signed-in accounts also store Discord ID, display name and avatar reference.
No chat messages, email addresses, keystroke streams, browser fingerprints or analytics advertising services are collected. Browser preferences are local. Model inputs contain only game state and fixed questions, never your Discord identity.
Personal evidence is available only to the match owner. Community leaderboard access uses a short-lived Discord launch grant. World rankings expose a public player identifier and display name.
Exports may contain your community IDs. Review them before sharing. Hash links detect alteration only relative to a trusted retained hash; they are not a digital signature.
